# Arquitetura de Software - Modelo C4

Esta pasta contém os diagramas arquiteturais do EduClass, baseados no Modelo C4.

* **Nível 1 (Contexto):** Visão geral de como os diferentes utilizadores e sistemas externos (como a API de IA e o Serviço de E-mail) interagem com o sistema principal.
* **Nível 2 (Containers):** Detalhamento técnico da Arquitetura em Camadas, mostrando o Frontend (Web e Mobile), a API Backend (NestJS), as Bases de Dados (PostgreSQL e Redis) e o Módulo de IA.
