# Sistema de Gestão de Sala de Aula Online 🎓

Bem-vindo ao repositório do projeto do nosso Sistema de Gestão de Sala de Aula Online, inspirado em plataformas como o Google Classroom. 

Este projeto atua como uma consultoria de Engenharia de Software, abrangendo desde a identificação do problema e levantamento de requisitos até a definição da arquitetura da solução.

## 🎯 Objetivo do Projeto
Conceber, modelar, documentar e defender tecnicamente a proposta de uma plataforma digital para apoiar a gestão de turmas, atividades, avaliações e comunicação entre professores e estudantes.

## 🛠️ Metodologias e Ferramentas Aplicadas
* **Gestão Ágil:** Kanban via GitHub Projects
* **Requisitos:** User Stories, Regras de Negócio e definição de MVP
* **Modelagem de Processos:** BPMN
* **Modelagem de Software:** UML (Casos de Uso)
* **Arquitetura de Software:** Modelo C4 e Decisões Arquiteturais

## 📂 Estrutura do Repositório

Neste repositório você encontrará todos os artefatos produzidos durante o projeto, organizados da seguinte forma:

* `docs/`: Documentação de requisitos, regras de negócio, MVP e diário da sprint.
* `bpmn/`: Modelagem dos processos de negócio do sistema.
* `uml/`: Diagramas de Casos de Uso.
* `c4/`: Diagramas de arquitetura (Nível 1 - Contexto e Nível 2 - Containers).
* `apresentacao/`: Material utilizado para a defesa técnica da solução em banca.

## 📌 Acompanhamento do Projeto
O gerenciamento de tarefas e o progresso das Sprints estão sendo controlados através do nosso GitHub Projects.
